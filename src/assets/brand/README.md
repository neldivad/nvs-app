# brand — NVS logo

Generated by the `nelbox` brand workshop from a mono source mark. The book + flipping-page brandmark.

## Use this one: `nvs-logo.svg`
The **theme-adaptive** logo — it uses `fill="currentColor"`, so it inherits the CSS `color` of its
container and flips automatically with focus (dark) / manuscript (light) mode.

```tsx
// colour it with the theme's thread/indigo token; it follows dark/light on its own
<span style={{ color: "var(--thread)" }}>
  <NvsLogo />              {/* import nvs-logo.svg */}
</span>
```
- **focus (dark):** thread = `#818cf8`  → logo renders light indigo
- **manuscript (light):** thread = `#4f46e5` → logo renders deep indigo

## Fixed variants — `variants/`
When you need a locked colour (favicon, og-image, external deck), not the adaptive one:
| file | use |
|---|---|
| `nvs-logo-light.{svg,png}` | `#4f46e5` — on light backgrounds |
| `nvs-logo-dark.{svg,png}` | `#818cf8` — on dark backgrounds |
| `nvs-logo-black.{svg,png}` | solid black |
| `nvs-logo-white.{svg,png}` | knockout on dark |
